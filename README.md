ITE183_Lab2_Websocket

A WebSocket chat server built with the Bonezegei Scripting Language for ITE183 Lab 2. Supports real-time multi-client message broadcasting and serves a custom 404 page for undefined routes.

Features
HTTP server that serves static files from the public/ folder
WebSocket connection handling (connect, message, disconnect events)
Real-time message broadcasting to all connected clients
Custom 404 page for undefined routes
Keep-alive heartbeat to prevent idle connection timeouts
How to run
Install Bonezegei Scripting Language (v1.3.3 or later)
Run bzg install to install dependencies
Run bzg run to start the server
Open the server URL in your browser (defaults to port 8000)
